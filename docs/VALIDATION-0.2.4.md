# 0.2.4 验证记录

本版同步账号启动身份修复与官方模型发现修复，并保留公开版的便携路径、环境变量目录和内置运行时支持。

## 验证范围

- 用真实临时目录联接验证可执行文件身份；拒绝同名不同文件、无法确认身份的进程和已回收 PID。
- 模拟额外辅助进程、窗口延迟、标记写入失败、短暂检查失败和进程退出，确认立即保留启动回执且不会重启或接管其他窗口。
- 账号模型迁移仅移除根层静态目录及其旧模型选择，保留备份、认证、其他配置、注释、换行以及后续官方模型选择。
- 重复启动无覆盖时不写配置；拒绝目录重叠、自定义端点、非法配置、备份失败和并发编辑。
- 账号未固定模型时，新导入聊天使用官方默认；旧对话的模型选择、历史内容及 SOTA 回流继续保留。
- 浏览器隔离测试使用本地单次写入消除 Windows 提前拒绝请求时的分段发送竞态，仍严格断言 403、无跨域放行、无上游请求，并补测未发送正文和跨域健康查询。

完整源码回归、冻结包校验及产物测试由本版发布闸执行；最终运行结果以对应 tag 的 CI 日志为准。

## 本地发布闸结果

- 完整回归：811 项，成功，跳过 7 项（6 项需要已生成产物，1 项需要 Windows 开发者模式的符号链接权限）。
- 冻结包生成、隔离运行时导入和完整性校验通过；产物专用测试随后运行 12 项，全部通过。
- 浏览器隔离重复执行 30 次通过；反向对照能检出 4 种外部健康查询放行错误。
- 本地验证使用真实 Windows 8.3 临时路径别名，不安装或替换现有程序。安装器由 Windows 发布工作流构建。

## 模型与账号边界

公开版本不内置一份所谓固定的 Free 账号模型表。显示/隐藏、默认模型、权限和更新由官方客户端及服务决定；联网情况、客户端版本和账号灰度可能影响返回结果。

普通配置审查保持只读。只有正常退出后、持有启动和历史互斥锁的账号直登准备步骤，才会显式备份并撤销旧静态模型覆盖。SOTA/API 的模型目录和凭据不变。

测试使用临时合成 profile，不为验收停止真实桌面会话；公开源码和下载包不含个人配置、密钥、聊天记录、数据库或运行日志。
