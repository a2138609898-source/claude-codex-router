# 0.2.2 验证记录

本版新增独立 ChatGPT 账号入口，并补齐账号与 SOTA 的离线增量历史往返。发行包仍使用内置
运行环境；不包含任何开发设备上的 profile、凭据、对话、日志或数据库。

## 专项回归

Windows / Python 3.11 下的 89 项账号切换及历史专项测试已通过，包括：

- 按钮互斥、取消、重复点击、窗口身份及未登录状态；账号启动不依赖 SOTA 密钥。
- 配置与凭据保持原样，账号 endpoint/认证覆盖及 profile 重叠时拒绝继续。
- 来源只读、目的增量、分页祖先、名称/项目/置顶/归档、冲突分支和多轮无重复往返。
- 原生压缩、多 Zstandard 帧、截断检测、压缩/未压缩副本、格式迁移后的真实追加与双侧分支。
- 事务备份、漂移拒绝、失败恢复、真实 PowerShell 父进程的锁与进程身份交接。

Python 3.12 的实际启动解释器也通过同一历史核心的 68 项回归。测试仅使用临时合成 profile；
活动 App 的拒绝写入由专门用例覆盖，不为测试终止真实桌面或后台。

## 发布闸

本地公开树的完整源码回归为 786 项通过（构建前 7 项产物用例按条件跳过）；冻结包构建后，
11 项产物测试全部通过，补齐了这些检查。源码、冻结包摘要及内置运行时校验均通过。
另以真实 PowerShell 父进程运行冻结版账号 CLI 两次，输入为压缩的临时合成历史，验证增量回传
及第二次零写入；冻结模块路径、历史锁、生命周期锁及请求目录均与打包启动器一致。

`Build-Release.ps1` 先运行完整源码回归，再构建冻结包，检查所有文件的摘要及运行时，最后执行
带产物的 `test_product_packaging.py`。内置运行时必须导入账号历史模块并完成 Zstandard 往返，
不能通过开发机器的 Python 依赖掩盖漏打包。压缩库的版本元数据及许可证一并打包。

Windows 发布工作流重新安装声明的构建依赖，执行相同验证后生成安装 EXE、便携 ZIP 和
`SHA256SUMS.txt`；发布任务只有在构建成功后才能上传。完整结果见
[Windows release](https://github.com/a2138609898-source/claude-codex-router/actions/workflows/release.yml)。

公开树隐私检查及 PowerShell 解析检查通过。原有可移植路径、首次供应商配置、路由与压缩摘要、
旧两向/三向同步和退出后维护均由原回归套件继续覆盖。

## 使用边界

独立账号 profile 必须已有有效配置及 Codex 建立的历史库。缺失或不兼容时只提示，不重建、
覆盖或清空已有账号目录。关闭管理器不等于退出 Codex；实际历史安装只在 App 和 backend 均已退出、
生命周期锁和历史锁正确交接后执行。此功能不提供 ChatGPT 网页或跨机器云历史同步。
