# 0.2.3 验证记录

本版包含 0.2.2 的账号直登、双向增量历史补齐和原生压缩历史支持，并修正公开 Windows CI
暴露的路径身份及测试依赖问题。0.2.2 标签保留，但其构建失败，没有发布可下载产物。

## 本地复现与针对性回归

- 使用 Win32 返回的真实 8.3 别名，不用字符串模拟短路径。
- 新增的历史清单、侧栏主机映射两项测试在修正前分别出现错误和失败，修正后通过。
- 以短路径 TEMP 重跑 8 项关键用例全部通过：压缩续写及备份、安装失败回滚、中断恢复、
  拒绝覆盖外部改动、项目和主机身份、提交前漂移、长短路径清单一致及主机别名合并。
- 测试夹具先统一物理路径拼写，保证故障注入实际命中目标；临时前缀保持短小，为分页、
  解压及备份子目录预留 Windows 路径长度空间，不通过放宽生产边界检查来通过测试。
- 94 个 Python 文件和 21 个 PowerShell 文件通过语法检查。公开树隐私扫描不允许真实
  供应商信息、个人路径、凭据、聊天记录、数据库或运行日志进入提交。

## 完整发布闸

完整源码套件包含 788 项用例；条件跳过及最终结果以对应 tag 的 CI 日志为准。
`validate` 安装 `requirements-build.txt`，因此既有压缩库，也有白名单测试实际使用的
PyInstaller 元数据收集器和可选 TLS 依赖。

`Windows release` 从同一 tag 运行完整源码回归，然后构建冻结包、校验文件摘要与内置运行时、
执行带产物的打包测试，最后生成安装 EXE、便携 ZIP 和 SHA256SUMS。发布任务依赖构建成功，
不会将本机旧包冒充新版本上传。

- [验证工作流](https://github.com/a2138609898-source/claude-codex-router/actions/workflows/validate.yml)
- [Windows 发布工作流](https://github.com/a2138609898-source/claude-codex-router/actions/workflows/release.yml)

## 保持的边界

不迁移或重写个人模型、供应商、登录及密钥配置；原两向/三向同步和退出后维护引擎保持不变。
实际账号历史安装仍要求 App 与 backend 都已退出，并取得已有生命周期和历史锁。
测试只使用临时合成 profile，不为验证终止真实桌面会话。此次发布准备不替换本机正在使用的安装目录。
